# Contributing

This repository is a read-only mirror of the TypeScript SDK's source. It is rewritten from the GunSpec monorepo on every stable release, so a commit made here directly would be overwritten.

- **Found a bug or want a feature?** Open an issue here. That is the fastest route.
- **Have a fix?** A pull request is welcome. It is read, applied upstream by hand, and reaches this repository with the next release. The pull request itself is then closed.
- **A question about the API rather than the SDK?** See [docs.gunspec.io](https://docs.gunspec.io).
